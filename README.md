# Mumma's Birthday Website

A one-page birthday website made by Vaanya. It uses plain HTML, CSS, and JavaScript, so there is nothing to install.

## Add your photos

Put up to six JPG photos in `assets/photos/` and name them exactly:

- `photo-1.jpg`
- `photo-2.jpg`
- `photo-3.jpg`
- `photo-4.jpg`
- `photo-5.jpg`
- `photo-6.jpg`

## Add your birthday video

1. Export your video as MP4 (H.264 is the safest format for browsers).
2. Name it `birthday-message.mp4`.
3. Put it inside `assets/videos/`.

Try to keep the video below 100 MB. GitHub blocks individual files larger than 100 MB, and smaller videos load much faster on phones.

## Personalize the words

Open `index.html` in VS Code and search for any sentence you want to replace. You can also change the main colors at the top of the `<style>` section under `:root`.

## Preview it

Double-click `index.html` to open it in your browser. Refresh after making changes.

## Publish free with GitHub Pages

1. Create a new public GitHub repository, for example `moms-birthday`.
2. Upload everything in this folder, keeping the `assets` folders intact.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then click **Save**.
6. GitHub will show your shareable link after a minute or two.

Important: upload the contents of this folder to the repository root. `index.html` should not be inside another folder.
